# debate-game
Interactive Team Debate Game Web App – Random team selection, round timers, live scoreboard, winner animations. Made for classroom competitions using Python Flask
Debate Competition Web App
An interactive and modern web application for conducting classroom debate competitions between two teams. Built with Python Flask, this project allows teachers to:

Randomly split students into Team A and Team B based on class strength.

Randomly select one participant from each team for every debate round.

Provide a set of debate topics from a customizable list.

Track debate times with a built-in timer (start, pause, reset).

Award points to winning roll numbers, with real-time animated confetti celebrations.

Display a live, rank-sorted scoreboard showing roll numbers, scores, and timing records.

Fully resets between sessions with a "Reset Game" feature.

Easy navigation between the debate "arena" and the scoreboard.

All logic runs entirely in the browser and simple Flask backend—no registration needed!

Perfect for teachers and organizers wanting to run fair, engaging, and fast-paced classroom debates!
